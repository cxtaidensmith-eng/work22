## Model definition

SEPS-Q v1 uses:

- three private query tokens;
- one shared `norm_kv` and multi-head attention block;
- three private `norm_out` and FFN blocks;
- the original one-vs-rest auxiliary supervision;
- the unchanged Message MLP, Global Message, DIFFormer, and classifier path.

Original Query contains 853,131 parameters. SEPS-Q contains 778,251
parameters, a reduction of 74,880 parameters (about 8.78%).

## Fixed protocol

- Loss: `L_main + L_AD_rest + L_CN_rest + L_SMCI_rest`
- Orthogonality loss: disabled
- Optimizer: Adam
- Scheduler: `CustomCosineAnnealingLR(T_max=400)`
- Best-epoch ordering: ACC, then Macro-AUC, then Macro-F1
- No multi-seed ensemble, hyperparameter search, or probability fusion

SEPS-Q produced three fewer correct OOF classifications. In the paired hard
classification comparison, Original Query was uniquely correct for 26 subjects
and SEPS-Q was uniquely correct for 23 subjects. There were 49 discordant
subjects; the exact McNemar p-value was 0.77545.

SEPS-Q kept the number of correctly classified AD subjects unchanged, reduced
sMCI-to-AD errors from 10 to 7, and increased correct sMCI classifications from
296 to 298. However, CN-to-sMCI errors increased from 11 to 16. This is
consistent with improved ranking quality but slightly weaker hard-classification
ACC and BACC.

## Limitations and conclusion

The fold0 ACC improvement did not reproduce consistently across all ten folds.
Under the fixed historical exploratory protocol, Original Query remains the
stronger hard-classification baseline. SEPS-Q preserves nearly the same
Macro-F1 with 8.78% fewer parameters and improves pooled Macro-AUC by about
0.71 percentage points, but it is not an ACC replacement.

The accurate interpretation is therefore: SEPS-Q v1 is a parameter-efficient
shared-evidence candidate with improved ranking quality, while Original Query
remains the current accuracy baseline. No subsequent architecture, fusion, or
additional ablation was implemented as part of this result.
