二、模型创新

Original Query Pool：private Query ×3 + private norm_kv/MHA ×3 + private norm_out/FFN ×3。

SEPS-Q v1：private Query ×3 + shared norm_kv/MHA ×1 + private norm_out/FFN ×3。

三个分支先用同一套 Attention 读取共享多模态证据，再由独立 FFN 形成类别语义。Modal Encoder、shared Modal Transformer、OVR auxiliary、concat + Message_MLP、Global_Message add、DIFFormer 和 classifier 均保持不变。没有新增 attention、graph、router、loss 或 ensemble。

三、参数量

减少：74,880，约 8.78%。

三个 private Query、共享 Attention 和三个 private FFN 均获得有效梯度；无 NaN/Inf。

独立 FFN 将共享证据转换成了明显不同的类别语义表示，没有发生 branch collapse。

Query gradient 随训练快速趋近于零，而 shared Attention 和 private FFN 在训练后期仍保持非零梯度。这支持：当前性能主要依赖共享证据编码与 private semantic transformation，而不是三个 Query token 的模态选择。

七、结论

SEPS-Q v1 在 fold0 同时实现：ACC 提升 1.67 个百分点；Macro-F1、Macro-AUC、Weighted-F1 提升；参数量减少约 8.78%；获得更清晰的“共享证据读取 + 私有类别语义变换”解释。

因此它同时满足当前阶段的性能与创新性目标，并优于此前完整共享 Query Pool 的 S0。

但 BACC 下降说明 AD 少数类仍是风险点。当前结果来自单个 fold0，并沿用历史 test-fold best-epoch 探索协议，不能直接宣称十折泛化提升。

八、下一步建议

优先将 SEPS-Q v1 作为唯一候选进入 10-fold single-seed 验证，与已有 Original Query 10-fold OOF 直接比较。

暂不继续堆叠新模块。若十折仍保持 ACC/Macro-F1/AUC 优势，再补一个 fold0 镜像机制消融（private Attention + shared FFN）用于论文归因。

当前实验完成后停止，没有自动实现其他模型。
