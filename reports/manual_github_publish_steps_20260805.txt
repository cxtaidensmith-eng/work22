不要运行：

git add .

==================================================
步骤 4：提交前检查
==================================================

查看 staged 文件：

git diff --cached --name-only

确认没有 checkpoint、缓存：

git diff --cached --name-only | Select-String -Pattern '\.pt$|\.pyc$|__pycache__'

预期：没有输出。

查看提交规模：

git diff --cached --stat

检查空白或冲突标记：

git diff --cached --check

预期：没有错误输出。

最后查看状态：

git status --short

说明：

- staged 文件左侧会显示 M 或 A。
- .pt 文件不应出现。
- Config/T_ADNI3_tune_light_gm64_dif_lr006_wd0007.ini 可能仍显示未暂存 M，但其 git diff 为空，本次可忽略。

如果误 stage 了某个文件，用以下命令仅取消暂存，不删除文件：

git restore --staged -- '文件路径'
