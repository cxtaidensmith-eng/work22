五、机制判断边界
correct alignment support under primary ACC criterion=False
只有 S2 优于参数匹配 S1，且最佳点在激活后并有非零 anchor contribution，才支持正确 OVR 对齐贡献。
若 Original Query 优于 S0/S2，说明共享整个 Query Pool 的容量损失仍然重要。
本结果使用 test-fold best epoch，按既定历史协议仅作为探索性 fold0 证据，不是无偏泛化估计。

七、最终研究判断
1. 共享整个 Query Pool 的 S0 比 Original Query 低 1.67 个 ACC 百分点，并且 BACC、Macro-AUC 同时下降；三个独立 Query Pool 的表示容量仍有贡献，不能只把 baseline 优势归因于三个 query token。
2. S1 错配 anchor 取得最高 ACC/Macro-F1，S2 正确 anchor 反而比 S1 低 1.67 个 ACC 百分点、2.99 个 Macro-F1 百分点和 0.90 个 Macro-AUC 百分点。因此本实验不支持“正确 OVR 判别方向形成了有效类别语义绑定”。
3. S1 相对 S0 的提升说明 class-dependent query perturbation 可能具有优化或正则化作用；由于错配映射同样甚至更有效，该提升不能解释为类别对应关系正确。
4. S2 最佳 alpha=-0.011720，表示最佳点使用了定义方向的反向；这进一步削弱“正确方向被模型采用”的机制解释。共享的有符号 alpha 仍存在方向翻转歧义。
5. S1 虽在 ACC、Macro-F1 和 Weighted-F1 上超过 Original Query，但 Macro-AUC 仍低约 0.0109；且结果仅来自历史 test-fold best-epoch 的单个 fold0，不能据此替代十折 baseline 或宣称泛化提升。
6. 建议当前 OSFQ-ID 路线停止扩展，不立即运行10-fold。若以后继续，首先需要解决可辨识性，例如预注册非负 alpha 并增加参数匹配的随机方向对照；这属于新实验，当前未实现。
